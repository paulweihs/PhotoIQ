# Corpus Build Instructions — Option A

**Objective:** Rebuild reference corpus with 40 library photos and their existing Claude-generated descriptions

**Prerequisites:**
- Valid library photos in `photoiq.db` with existing Claude-generated descriptions (PhotoIQ app must have analyzed photos)
- Evaluation database (`evaluations.db`)

---

## Step 1: Run Corpus Builder

### Default (40 photos)
```bash
dotnet run --project tools/PhotoWell.Eval -- --build-corpus
```

### Custom Count (e.g., 50 photos)
```bash
dotnet run --project tools/PhotoWell.Eval -- --build-corpus 50
```

### With Custom Database Paths
```bash
dotnet run --project tools/PhotoWell.Eval -- --build-corpus 40 \
  --eval-db path/to/evaluations.db \
  --main-db path/to/photoiq.db
```

## What the Tool Does

### Phase 1: Sample Photos
- Queries `photoiq.db` for up to 40 random photos
- Verifies all source files exist on disk
- Returns valid file paths for next phase

### Phase 2: Retrieve Existing Descriptions
- Retrieves existing Claude-generated descriptions from `media_files` table
- Descriptions were already generated by PhotoIQ's vision analysis
- No API calls made in this step

### Phase 3: Insert into Corpus
- Inserts each photo + description into `reference_corpus` table
- File paths point directly to original photos (not thumbnails)
- Timestamps recorded, `generated_by` set to "claude-code"

### Phase 4: Validate
- Verifies all inserted entries have valid source + image files
- Reports any discrepancies
- Returns success status

## After Build: Next Steps

### 1. Verify Corpus
```bash
dotnet run --project tools/PhotoWell.Eval -- --corpus-status
```

Expected: `Reference corpus: 40 images`

### 2. Re-run v16 Evaluation
```bash
dotnet run --project tools/PhotoWell.Eval -- --optimize-prompt 40 \
  --prompt "$(cat tools/PhotoWell.Eval/v16_prompt.txt)"
```

This will:
- Sample all 40 corpus images
- Run v16 prompt through Ollama (llama3.2-vision)
- Compare against Claude descriptions
- Report similarity scores (Jaccard)
- Show improvement vs v15c baseline

### 3. Review Results
Look for:
- `Avg similarity: >0.245` (target for 10% improvement)
- `Worst matches: >0.150` (improvement on problem cases)
- No increase in empty descriptions or loops

### 4. Decision
- **If avg similarity >0.245:** Deploy v16
- **If avg similarity <0.245:** Iterate on v17 improvements
- **If 0.230-0.245:** Good progress, decide on threshold

## Troubleshooting

### "No photos available to sample"
- **Cause:** PhotoIQ library is empty
- **Fix:** Import photos into PhotoIQ app first

### "ANTHROPIC_API_KEY environment variable not set"
- **Cause:** API key not exported in shell
- **Fix:** Set environment variable per Step 1 above

### "Empty response" for many photos
- **Cause:** API rate limiting or temporary issues
- **Fix:** Re-run command, it will skip already-inserted entries
- **Note:** Tool uses `INSERT OR IGNORE`, so duplicates won't be re-inserted

### "Invalid entries after insert"
- **Cause:** Photos deleted or moved after sampling
- **Fix:** Rebuild corpus again, run --rebuild-corpus to clean
